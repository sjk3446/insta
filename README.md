# Instagram 로컬 다운로드

Windows용 다운로드 프로그램과 GitHub Pages 시작 화면입니다. Pages 화면에서 프로그램을 열면 로컬 브라우저의 작업 화면(`http://127.0.0.1:17861/`)으로 이어집니다.

## PC마다 한 번 설치

1. 저장소 ZIP을 풀고 `install.cmd`를 실행합니다. Windows와 Python 3.10 이상이 필요하며, 다운로드 라이브러리가 없으면 설치 프로그램이 추가합니다.
2. PC에서 사용할 비밀번호를 입력합니다. 비워 두면 임의 비밀번호를 만들어 설치 창에 한 번 표시합니다.
3. 설치 후 표시되는 로그인 화면에 비밀번호를 입력합니다. 같은 브라우저에서는 인증 쿠키를 지울 때까지 최대 30일 동안 다시 입력하지 않습니다. 웹에 비밀번호 관리 화면은 없습니다.
4. 설치 후에는 Pages의 **다운로드 프로그램 열기** 또는 ZIP의 `open.cmd`로 프로그램을 엽니다. 브라우저가 프로그램 실행 확인을 표시하면 설치한 **Instagram Local Downloader**가 맞는지 확인하고 엽니다.

공개 계정에서 사진, 동영상 또는 둘 다를 선택하고 저장 폴더를 지정합니다. 계정 메모, 다운로드 이력, 로그, 이어받기 기준은 `%LOCALAPPDATA%\InstagramLocalDownloader\.local\state.sqlite3`에 PC별로 저장됩니다. 다른 PC의 이력은 공유되지 않습니다. 비밀번호는 PC에 검증용 해시로만 저장됩니다.

게시물 등록일은 **전체**, **최근 1달**, **최근 3달**, **기간 지정** 중 선택합니다. 최근 기간은 이 PC의 오늘 날짜에서 달력상 1개월 또는 3개월 전부터 오늘까지입니다. 기간 지정은 시작일과 종료일을 모두 포함합니다. 예를 들어 특정 기간에 등록된 사진만 받으려면 파일 유형을 **사진**, 등록일을 **기간 지정**으로 선택합니다.

저장된 계정을 불러오고 **이어받기 → 지난 다운로드 이후**를 선택하면 같은 저장 폴더에서 마지막으로 저장한 게시물의 등록 시각을 기준으로 이후에 올라온 콘텐츠를 받습니다. 사진과 동영상의 기준은 따로 유지합니다. 처음 받는 유형은 해당 폴더의 다른 유형에서 마지막으로 저장한 게시물을 기준으로 삼습니다. 기준 시각이 같아도 이미 처리하지 않은 게시물은 포함합니다. 첫 다운로드에는 **미처리 게시물** 또는 **전체 재확인**을 사용하세요.

파일 유형을 **사진**으로 두고 **사진 미리보기**를 누르면 조건에 맞는 게시물을 골라 저장할 수 있습니다. 여러 장 게시물에는 첫 번째 사진만 표시되며, 선택한 게시물의 사진은 모두 저장됩니다.

## GitHub Pages 게시

`sjk3446/insta`의 기본 브랜치에 소스 파일을 올리고 **Settings → Pages → Build and deployment**에서 **Deploy from a branch**, **main**, **/docs**를 선택합니다. 게시가 완료되면 `https://sjk3446.github.io/insta/`에서 시작 화면을 엽니다.

비공개 저장소의 Pages 사용 가능 여부는 GitHub 플랜에 따릅니다. 시작 화면에는 비밀번호나 작업 이력이 포함되지 않습니다. 설치 파일 링크는 저장소 ZIP을 가리키므로 저장소가 비공개이면 GitHub 접근 권한이 있는 브라우저에서 다운로드해야 합니다.

인스타그램이 공개·비로그인 상태에서 제공하는 미디어를 원본 바이트 그대로 저장합니다. 조회 제한이 발생하면 작업 로그에 표시됩니다.

작업 기록에서 진행 중인 다운로드의 **중지** 버튼을 누르면 요청량 제한 대기를 끝내고 작업을 중지합니다. 이미 진행 중인 네트워크 요청은 응답이나 시간 제한을 기다릴 수 있습니다. 저장이 완료된 파일과 처리 기록은 보관되며, 미완성 파일은 정리합니다.
